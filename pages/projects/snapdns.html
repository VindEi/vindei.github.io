SnapDNS

Cross-platform DNS manager featuring a clean Flutter UI backed by a fast .NET background service (native on Android).

View Source
Tap image to switch theme

Split-Process Design

The unprivileged Flutter GUI runs in user space, communicating via local IPC with a lightweight .NET background daemon.

Cross-Platform

Consistent controls and responsive performance across Windows, macOS, Linux, and Android devices.

Encrypted DNS

Easily configure, manage, and enforce DNS-over-HTTPS (DoH) and DNS-over-TLS (DoT) across active network adapters.

Presets & Custom Profiles

Switch between fast resolvers (Cloudflare, Google, Quad9) or add your own custom upstream DNS servers.

Built-in Diagnostics

Test DNS latency and flush system DNS resolver caches directly from the client.

Private & Open Source

100% open-source (GPLv3) with zero telemetry, running entirely on your machine.
